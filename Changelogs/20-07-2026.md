# Changelogs - 20/07/2026

- Renamed the **Software Security** column to **AI Security** across the roadmap table, generated roadmap images, specialty filters, and certification data.
- Added **Create your own Roadmap** (desktop only): select up to 10 certifications in order, generate and download a PNG client-side.
- Moved **Request Feature** next to **Request Addition** and **Submit Review** in the desktop roadmap header; removed the duplicate bottom-right button.
- Updated **community-led** and **July 2026** styling to blue (`#3B82F6`); community-led text is now underlined.
- Updated the roadmap chatbot theme from teal to blue to match the site palette.
- Empty certification review links now display **N/A** on desktop tooltips and **No Review** on mobile cards.
- Implemented client-side conditional rendering for the roadmap table and homepage footer - only one mobile or desktop layout mounts at a time.
- Skipped desktop grid computation on mobile to avoid building the 27×39 grid when it is not displayed.
- Mobile domain sections and descriptions now use accordion behavior (only one domain and one description open at a time).
- Added horizontal divider lines in the Create Roadmap popup between instructions, beta disclaimer, and selection count.

## Bugs & Glitches [Unresolved]

- Roadmap page may still lag on devices without hardware acceleration (empty grid cell animations, `backdrop-blur`, and visual effects not yet optimized).

## Bugs & Glitches [Resolved]

- Fixed inconsistent inner margins on generated roadmap image field boxes (specialties, sub-specialties, and description were inset while other fields were flush).
- Fixed full name text being clipped in generated roadmap images for long certification names.
- Fixed duplicate mobile/desktop roadmap UI and footer both rendering in the DOM at the same time (hidden via CSS).
- Fixed mobile review placeholder showing unclear **N/A** text - now shows **No Review**.
- Fixed Create Roadmap popup title capitalization (**Create your own Roadmap**).
- Fixed empty `reviewLink` values producing broken review links across the roadmap UI.
